NoFlyers is a per-app Xposed module for preventing AppsFlyer crashes when Google
App Set ID services are unavailable or intentionally hidden.

### Included

- Compatibility mode using AppsFlyer’s supported `disableAppSetId()` API.
- Optional failed-App-Set mode for malformed success-callback crashes.
- Full AppsFlyer startup and event blocking mode.
- Exact-package overrides and a one-tap PicsArt preset.
- Vector/LSPosed recommended scope for `com.picsart.studio`.
- Optional diagnostic Xposed logging.

### Install

Install `NoFlyers-v0.1.5.apk`, enable it in Vector/LSPosed, and scope it only to
the target applications. For PicsArt, add the preset and scope only
`com.picsart.studio`; do not scope Google Play services or the Play Store.
